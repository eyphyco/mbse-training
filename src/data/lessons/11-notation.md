## コメント・根拠・問題・制約 {#notation-comment}
items: mu-comment
term: コメント | こめんと | 右上の角が折れた長方形。要素の説明。アンカー（破線）で要素と結ぶ
term: 問題 | もんだい | «problem»。設計上の課題・欠陥を書き添えるコメント
term: アンカー | あんかー | コメントと、コメントが説明する要素を結ぶ破線

### 4 種の書き添え

| 記号 | 名前 | 中身 |
| --- | --- | --- |
| 角の折れた長方形 | コメント | 説明 |
| 同 + `«rationale»` | **根拠** | なぜそう決めたか |
| 同 + `«problem»` | **問題** | 欠陥・課題 |
| `{ }` で囲んだ文 | **制約** | 守るべき条件（`{mass <= 1500}`） |

### 見分けの要点

- コメントは**意味を持たない説明**。モデルの規則にはならない
- `{ }` の制約は**規則**。モデルが守るべき条件
- 根拠と問題はコメントの一種（ステレオタイプで区別）

## 図枠と、その縁に載るもの {#notation-frame}
items: mu-frame

### 図枠の縁

図枠は**ヘッダの対象そのもの**を表す。だから縁に載るものは、その対象の出入口になる。

| 図 | 縁に載るもの | それは何か |
| --- | --- | --- |
| `ibd` | 小さな四角 | 囲みブロック自身の**ポート** |
| `par` | 小さな四角 | 囲みが制約ブロックのとき、その**パラメータ** |
| `act` | 長方形 | アクティビティの**パラメータノード**（全体の入出力） |
| `sd` | メッセージの端 | ゲート（外とのやりとり） |

### 図の説明

図には**図の説明**（diagram description）を付けられる。コメントの形で、版・完成度・説明・参照を書く。

| 欄 | 中身 |
| --- | --- |
| version | 版 |
| completion status | どこまでできているか |
| description | 図の説明 |
| reference | 参照する文書など |

## ステレオタイプ {#notation-stereotype}
items: mu-stereotype
term: プロファイル | ぷろふぁいる | ステレオタイプを定義して入れておく入れ物。SysML 自体も UML のプロファイル

### 読み方

`«block»` `«requirement»` `«satisfy»` のような **ギュメ（« »）** で囲んだ名前がステレオタイプ。
要素の**種類**を示す。同じ長方形でも `«block»` ならブロック、`«valueType»` なら値型。

### 表し方

| 表し方 | 例 |
| --- | --- |
| 名前の上に `«»` | `«block»` |
| 複数 | `«block, system»`（1 つの «» にカンマで並べる） |
| アイコン | 棒人間（アクター）など |
| ステレオタイプのプロパティ | `{unit = kg}` や区画で |

### SysML はプロファイル

SysML 自体が UML の**プロファイル**で、`«block»` などのステレオタイプの集まり。
だから SysML の要素の多くは「UML の要素 + ステレオタイプ」でできている（ブロック = UML のクラス + `«block»`）。

## ステレオタイプを適用する {#notation-apply}
items: mbf-apply-stereotype

### Model Builder Fundamental で問われる範囲

**ステレオタイプを使う**（既にあるものを要素に適用する）ことだけ。プロファイルやステレオタイプを**作る**ことは範囲外（syllabus に明記）。

### 手順

1. 使うステレオタイプを持つ**プロファイルをパッケージに適用**する
2. 要素にステレオタイプを適用する（`«system»` など）
3. ステレオタイプのプロパティに値を入れる（`{criticality = high}`）

### 確かめる観点

| 観点 | 正しい形 |
| --- | --- |
| 表記 | 名前の上に `«»`。複数はカンマ |
| 適用先 | ステレオタイプが拡張する種類の要素だけ（ブロック用のものを要求に付けない） |
| プロパティ | `{名前 = 値}` |
